# My Sponge Plugin

This is a Sponge plugin for Minecraft, designed to enhance gameplay and provide additional features.

## Features

- Custom gameplay mechanics
- Integration with Sponge API
- Easy configuration

## Requirements

- Minecraft version: 1.21.4
- Sponge API version: 14.0.0
- Java 17 or higher

## Building the Plugin

To build the plugin, ensure you have Gradle installed and run the following command in the project root directory:

```
./gradlew build
```

This will compile the plugin and create a JAR file in the `build/libs` directory.

## Running the Plugin

1. Place the generated JAR file into the `mods` folder of your Sponge server.
2. Start the server.
3. The plugin should be loaded automatically.
